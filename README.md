
# Scrapper de Diários Oficias

Esse projeto faz o scrapping dos diários do Governo do Piauí, Tribunal de Justiça do Piauí e da Prefeitura de Parnaíba.

## Funcionalidades
-  Download de diários no formato PDFs
- salvar metadados em um arquivo excel (nome do diário, data de publicação, número do diário e link quando possível)
- Fontes:
    - https://www.tjpi.jus.br/transparencia/diarios
    - https://www.diario.pi.gov.br/doe/
    - https://dome.parnaiba.pi.gov.br/

- Busca na data especificada
## Guia de uso

Ao executar o script, especifique a data no seguinte formato: DD-MM-YY. Além disso, não esqueça de rodar o seguinte comando:

```bash
uv run playwright install
```
